# Patrol Rush — WEB-версия

Самодостаточная реализация игры на **HTML5 Canvas + ванильный JS** (без движков/зависимостей), для встраивания в обычный сайт. Повторяет механику Godot-оригинала, но живёт отдельно.

> Это «быстрый бриф» для новой сессии: что тут происходит, как всё устроено, где крутить.

## Запуск / встраивание
- **Локально:** открой `WEB/index.html` в браузере.
- **На сайте:** положи папку `WEB/` на любой статик-хостинг / в `<iframe src=".../index.html">`. Сборок и зависимостей нет.
- Синтаксис JS: `node --check WEB/game.js`.

## Управление
| Клавиша | Действие |
| --- | --- |
| `←`/`→` или `A`/`D` | Смена полосы — **дискретно: 1 нажатие = 1 полоса** (автоповтор игнорируется) |
| `SPACE` | Нитро (резкий разгон вперёд) |
| `ENTER` | Выстрел ракетой |
| `P`/`Esc` | Пауза |

## Суть / условия победы
- **Победа:** собери нитро и ракету; выстрел по **убегающей** машине → взрыв (Canvas-частицы) + «ПОБЕДА!».
- **Аварии (конец игры):** врезался в гражданского **или** попал ракетой по гражданскому.
- Промах ракетой мимо всего — просто расход ракеты, не авария.
- Рекорд в `localStorage["patrol_best"]`, очки = +1 за обгон.

## Ключевые механики (актуальное состояние)
- **Вся игра ускоряется по времени** (классический endless-runner), НЕ по очкам:
  `G.speed += SPEED_ACCEL*dt` (в `frame()`), старт `BASE_SPEED=175`, акк `SPEED_ACCEL=4.5`, потолок `SPEED_CAP=430`. От него завязано всё (дорога, трафик, призы).
- **Трафик** реально разгоняется: у каждой машины свой `fwd`, и её `vy` каждый кадр пере-целится в `scrollSpeed()-fwd` (см. `moveTraffic`).
- **Нитро** — сильный плавный бросок: `scrollSpeed()` = `G.speed * (1 + NITRO_STRENGTH*min(1,nitroTime/NITRO_DUR))`; `NITRO_DUR=1.6`, `NITRO_STRENGTH=2.0`. Запас — 1 заряд, приз приходит ~каждые 15 обгонов.
- **Ракета** — 1 заряд, приз через 4 обгона после нитро. `ENTER` стреляет вверх.
- **Анти-стена:** у ряда игрока (`DANGER_TOP..DANGER_BOT`, ~620..905) **не больше одной машины** — остальные ждут выше → «шах-мат»/непроезжаемый тупик невозможен, всегда есть свободная полоса.
- **Плотность:** до `MAX_PER_LANE=2` на полосу, спавн ~`SPAWN_EVERY=0.78`, грузовики `TRUCK_CHANCE=0.13`, анти-повтор модели подряд.
- **Убегающая машина** (вверху): никогда не проезжает сквозь трафик — считает свободный зазор полосы (`laneClearance`) и уходит заранее в самую свободную (`EMERGENCY=200`), в спокойные моменты блуждает.
- **Стартовый экран** содержит короткую справку («аркада, а не шахматы; проехать можно всегда»).

## Ассеты (`WEB/assets/`)
- `police_topdown.png` — игрок (полиция), фиксированный.
- `car_blue_sedan.png`, `car_yellow_compact.png`, `car_red_sports.png`, `car_black_suv.png` — легковые (трафик + кандидаты на врага).
- `truck_topdown.png`, `truck2_topdown.png` — грузовики (только трафик).
- `nitro.png`, `rocket.png` — призы. `nitro.wav`, `toyota-supra-turbo-car.mp3` — звук.
- `asphalt.png` — тайл текстуры дороги (копия Godot `MODELS/asfalt_2.png`).
- **Убегающая** каждый забег — **случайная** из 4 легковых; выбранная **не попадает в трафик** в этом забеге. Грузовики врагом не бывают.

## Соглашения по спрайтам/хитбоксам (в коде уже так)
1. **Ориентация:** код НЕ переворачивает картинки. Каждый PNG поставляется уже правильно ориентированным (нос по направлению движения). Сейчас спрайты корректные.
2. **Хитбокс из PNG:** в `vehicle()` длина хитбокса = `rw × (img.height/img.width)`; `rw` (ширина рендера) из карты `FILE_W`. Грузовик длиннее на PNG → длиннее хитбокс → нельзя «заехать в жопу грузовика» с хитбоксом машинки.

## Код (`WEB/game.js`, один файл)
- Реестр ассетов/ролей: `POLICE_FILE/CAR_FILES/TRUCK_FILES/NITRO_FILE/ROCKET_FILE`, `FILE_W`.
- `vehicle()` — фабрика (хитбокс из PNG); `scrollSpeed()` — скорость мира (с учётом нитро).
- Состояния: `menu|playing|paused|over`; экраны — HTML-оверлеи в `index.html`.
- Спавн/правила: `trySpawn/moveTraffic`; враг: `laneClearance/moveEnemy`; ракеты: `fireRocket/moveRockets`; призы: `spawnPickup/movePickups`; игрок: `movePlayer` (дискретные полосы); экономика призов по обгонам в `addScore`.
- **Тюнинг** — все константы вверху файла (скорость, нитро, спавн, хитбоксы).

## Известное / заметки
- `WEB/new_assets/` — папка, куда юзер кладёт новые спрайты (staging); в git НЕ закоммичена, можно игнорировать/чистить. Файлы оттуда копируются в `WEB/assets/`.
- Рендер: Canvas 2D, 540×960, масштабируется под окно (`fit()`).
