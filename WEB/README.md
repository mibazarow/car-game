# Patrol Rush — WEB-версия

Самодостаточная реализация игры на **HTML5 Canvas + ванильный JS** (без движков и зависимостей), предназначенная для встраивания в обычный сайт. Повторяет механику Godot-оригинала.

## Как запустить / встроить

- **Локально:** просто открой `index.html` в браузере.
- **На сайте:** положи папку `WEB/` на любой статический хостинг и встраивай как страницу или через `<iframe src=".../index.html">`. Никаких сборок и зависимостей.

## Управление

| Клавиша | Действие |
| --- | --- |
| `←` / `→` или `A` / `D` | Смена полосы |
| `SPACE` | Нитро |
| `ENTER` | Выстрелить ракетой |
| `P` / `Esc` | Пауза |

## Механика (как в оригинале)

- 4 полосы, вид сверху, бесконечная дорога с прокруткой.
- **Полиция** внизу, **убегающая** машина вверху (блуждает и объезжает трафик).
- **Трафик:** до 2 машин на полосу, «наследование скорости» лидера (нет наездов), анти-шахмат у линии игрока.
- **Очки** +1 за обгон, **рекорд** в `localStorage`, **сложность** растёт каждые 20 обгонов.
- **Нитро** — каждые ~15 обгонов; **ракета** — через 4 обгона после нитро.
- **Победа:** попади ракетой по убегающей машине → взрыв (Canvas-частицы) + «ПОБЕДА!». Ракета по гражданскому трафику — просто промах (не авария).
- Звук двигателя (mp3) и нитро.

## Ассеты (актуальные)

Файлы в `WEB/assets/`:
- `police_topdown.png` — игрок (полиция), фиксированный.
- `car_blue_sedan.png`, `car_yellow_compact.png`, `car_red_sports.png`, `car_black_suv.png` — легковые (трафик + кандидаты на «убегающую»).
- `truck_topdown.png`, `truck2_topdown.png` — грузовики (трафик; врагом никогда не бывают).
- `nitro.png`, `rocket.png` — призы.
- `nitro.wav`, `toyota-supra-turbo-car.mp3` — звук.

Роль «убегающей машины» каждый забег — **случайная** из 4 легковых; выбранная **не появляется в трафике** в этом забеге.

## ⚠️ Важно: соглашения по ассетам (спрайты и хитбоксы)

Игра **НЕ переворачивает и не поворачивает картинки в коде** — каждый спрайт должен приходить сразу в нужной ориентации.

1. **Ориентация.** PNG машины поставляется так, что **нос (перед) машины смотрит в направлении её движения**:
   - игрок (полиция) и убегающая машина едут «вперёд» (вверх по экрану) — нос вверх;
   - трафик едет навстречу игроку (вниз по экрану) — нос вниз;
   - прицепы/призы (нитро/ракета) — как удобно, желательно носом вперёд по направлению полосы.
   > Сейчас спрайты пока НЕ в этой ориентации — машины выглядят «задом-наперёд». Заменить PNG, код не трогать.

2. **Ширина.** Все машины приводятся к одной видимой ширине, чтобы помещаться в полосу. Рендер по ширине — код масштабирует высоту автоматически от пропорций PNG.

3. **Хитбокс из размера PNG (главное).** Хитбокс каждой машины вычисляется из реальных размеров её картинки:
   - **ширина** хитбокса — фиксированная (по ширине машины/полосы);
   - **длина** хитбокса = ширина_рендера × (высота_PNG / ширина_PNG).
   → Грузовик на PNG длиннее → PNG выше → **хитбокс длиннее**; маленький седан короче → хитбокс короче. Нельзя «заехать в жопу грузовика», получив хитбокс маленькой машинки.
   > Сейчас в `game.js` хитбоксы захардкожены по типу (`SIZE.hw/hl`). Задача — перевести на расчёт из `img.height / img.width`.
