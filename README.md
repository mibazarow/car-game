# Patrol Rush

Аркадная погоня с видом сверху, созданная на **Godot 4.7**. Ты — полицейский автомобиль внизу экрана, преследуешь убегающую машину по бесконечной четырёхполосной дороге. Объезжай трафик, обгоняй машины ради очков, подбирай нитро и держи погоню как можно дольше.

Это погоня в стиле endless-runner — нет экрана победы и конца. Просто выживай, набирай очки и бей свой рекорд.

*Платформа: macOS · Движок: Godot 4.7+ · Стиль: вид сверху*

---

## 🎮 Суть игры

Камера смотрит строго сверху на высокую узкую (портретную) дорогу. Твоя **полицейская машина** внизу, **убегающая машина** всегда держится вверху, а между ними — поток городского трафика, едущий навстречу.

Ты не выигрываешь, догнав противника, — гонишься бесконечно. Каждый обгон даёт очко, дорога ускоряется, чем дольше ты держишься, а любое касание трафика — авария и конец игры.

---

## 🕹️ Управление

| Клавиша | Действие |
| --- | --- |
| `←` / `→` или `A` / `D` | Смена полосы (влево / вправо) |
| `SPACE` | Использовать запасённое нитро |
| `P` / `Esc` | Пауза / продолжить |

Движение сглаженное и инерционное — машина плавно входит в полосу и кренится (yaw + roll) при перестроении, так что манёвры ощущаются как настоящее руление, а не телепорт.

## ✨ Особенности

- **Бесконечная четырёхполосная дорога** в современном стиле GTA-1: газон, асфальт с реальной тайловой текстурой, обочины, бордюры и бесшовная пунктирная разметка.
- **Процедурный трафик** — городские седаны четырёх цветов плюс два более медленных и крупных грузовика. Трафик не нагромождается и не образует непреодолимую стену — всегда есть свободная полоса.
- **Автономная убегающая машина** вверху, которая объезжает трафик и держит тебя в погоне.
- **Очки и рекорд** — +1 за обгон, лучший счёт сохраняется локально (`user://best.cfg`).
- **Плавный рост сложности** — скорость и плотность трафика постепенно растут с ростом счёта, с разумным потолком.
- **Нитро-буст** — подбери жёлтый диск на дороге, чтобы сохранить один буст (без накопления). Нажми `SPACE` — вся машина (корпус и хитбокс) рывком уходит вперёд; это ускорение, а не неуязвимость.
- **Честные коллизии** — хитбоксы совпадают с машиной и следуют за ней во время нитро: ты врезаешься в машины на пути, но не сквозь них.
- **Полный цикл состояний** — Меню → Игра ⇄ Пауза → Конец игры → заново / меню.
- **Физика вождения** — видимый поворот и крен корпуса при смене полосы.
- **Звук двигателя и нитро**, иконка окна и низкополигональная производительная сборка.

## 🚀 Как запустить

### Требования

- **Godot 4.7+** (разработано и протестировано на 4.7.2). Проект использует рендерер **GL Compatibility**.
- macOS (текущая целевая платформа).

### Импорт и запуск в редакторе

1. Открой **Godot 4.7+**.
2. **Импортируй проект**: *Import* → *Import Project* → выбери `project.godot` в этой папке.
3. Дождись завершения импорта (кеш `.godot/` пересоздастся).
4. Нажми **F5** (или *Play* → *Play Main Scene*). Игра запустится в портретном окне (~540×960, размер окна меняется).

### Из командной строки

```bash
godot --path /path/to/Patrol_Rush
```

Или запуск в headless (полезно для CI / валидации):

```bash
godot --headless --path /path/to/Patrol_Rush --scene scenes/Main.tscn
```

> **Заметка про звук:** WAV-ассеты импортируются после открытия проекта в редакторе. Если после свежего импорта звука нет, выполни `godot --headless --path . --import` один раз, чтобы собрать кеш `.import`.

## 📁 Структура проекта

```
Patrol_Rush/
├── project.godot          # Конфиг проекта: окно 540×960, портрет, GL Compatibility, иконка
├── autoload/
│   └── GameState.gd        # Синглтон: очки, рекорд, скорость, нитро, состояния игры
├── scenes/
│   ├── Main.tscn           # Корневая сцена: камера, свет, дорога, машины, HUD, меню
│   ├── PlayerCar.tscn      # Полицейская машина игрока (Area3D + GLB-модель)
│   ├── TrafficCar.tscn     # Обычная машина / грузовик трафика
│   ├── FleeingCar.tscn     # Убегающая машина (верх экрана)
│   ├── TrafficSpawner.tscn # Процедурный спавн трафика с пулом объектов
│   ├── RoadGenerator.tscn  # Бесконечная скроллящаяся дорога
│   ├── NitroPickup.tscn    # Подбираемый нитро-приз («камень на дороге»)
│   ├── NitroSpawner.tscn   # Периодически спавнит нитро-призы
│   ├── HUD.tscn            # Внутриигровой счёт / рекорд / индикатор нитро
│   ├── MenuScreen.tscn     # Стартовое меню
│   ├── PauseScreen.tscn    # Меню паузы
│   └── GameOverScreen.tscn # Конец игры + рестарт
├── scripts/
│   ├── player/player_car.gd
│   ├── traffic/traffic_car.gd
│   ├── traffic/traffic_spawner.gd
│   ├── road/road_generator.gd
│   ├── fleeing/fleeing_car.gd
│   ├── nitro_pickup.gd
│   ├── nitro_spawner.gd
│   ├── hud.gd
│   ├── menu.gd
│   ├── pause.gd
│   └── game_over.gd
└── MODELS/                 # Низкополигональные GLB-модели машин, текстуры, звук, иконка
```

### Как всё связано

- **`GameState`** (синглтон-автолоад) владеет всем глобальным состоянием: очки, рекорд, текущая скорость, заряд нитро и состояние игры (`menu` / `playing` / `paused` / `game_over`). Неигровые состояния замораживают мир через проверки в скриптах.
- **`RoadGenerator`** создаёт бесконечную четырёхполосную дорогу, которая скроллится к игроку и перерабатывает сегменты.
- **`TrafficSpawner`** + **`TrafficCar`** процедурно спавнят машины перед игроком, пулят объекты для производительности и следят за дистанцией + гарантией свободной полосы.
- **`PlayerCar`** обрабатывает смену полос со сглаживанием, поворот и крен; его хитбокс следует за корпусом во время нитро.
- **`FleeingCar`** держится вверху кадра и автономно объезжает трафик.

## ⚠️ Важно: модели машин не в git

Трёхмерные модели машин (`MODELS/*.glb`) — **большие бинарные файлы, и они в `.gitignore`** — их **нет** в репозитории. Свежий клон запустится (дорога, HUD, меню и логика игры работают), но машины будут невидимы, пока модели не появятся на месте.

Чтобы машины отображались, помести файлы моделей в `MODELS/`:

```
MODELS/
├── 1_police_hero_car_.glb      # Полицейская машина игрока
├── 2_city_car_beige_.glb       # Убегающая машина
├── 3_city_car_blue_.glb        # Трафик
├── 4_city_car_yellow_.glb      # Трафик
├── 5_city_car_green_.glb       # Трафик
├── 6_semi_truck_red_.glb       # Трафик (медленный, большой)
└── 7_semi_truck_white_.glb     # Трафик (медленный, большой)
```

Всё остальное — скрипты, сцены, текстуры дороги/трафика, звук и конфиг проекта — **закоммичено** и работает из коробки.

> **Ориентация моделей:** все модели смотрят вперёд (+Y вверх, нос к −Z в игре). При импорте в Godot нос указывает на +Z, поэтому каждый инстанс повёрнут на `rotation.y = 180°`, чтобы нос смотрел вперёд.
